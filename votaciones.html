Votaciones nominales de las Cortes

El voto nominal de cada diputado y senador es un hecho oficial y público: aquí se reproduce entero, con el reparto por formación. A diferencia de las piezas de prensa, este dato no se resume ni se adjetiva — se muestra tal cual, con enlace a la fuente oficial de cada sesión. La formación de cada voto es adscripción propia (análisis, ampliable); el grupo y el voto son el dato oficial. Elige una legislatura; dentro de cada una hay buscador de títulos y archivo mensual.
